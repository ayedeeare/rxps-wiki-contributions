# RXPS Wiki Contributor Templates

Welcome! This repo contains templates for contributing to the [RXPS Wiki](https://rxps.wiki).

## How to Contribute

1. **Fork this repository**
2. **Create or edit pages** using the templates below
3. **Submit a Pull Request** with your changes
4. **Wait for review** - a maintainer will review and merge your contribution

## Folder Structure

```
docs/
├── bosses/          # Boss guides
├── items/           # Item information
├── skills/          # Skill training guides
├── minigames/       # Minigame guides
├── guides/          # General guides
├── raids/           # Raid guides
├── economy/         # Economy guides
└── upgrades/        # Enchanting/upgrade guides
```

## Templates

Check the `/templates` folder for example page formats:
- `boss-template.md` - For boss guides
- `item-template.md` - For item pages
- `skill-template.md` - For skill guides
- `general-template.md` - For other pages

## Writing Guidelines

Write like a player explaining something to another player. Short sentences,
real numbers, no filler.

**Accuracy beats completeness.** RXPS has its own rates and its own drop
tables, so an OSRS number carried across is a wrong number and a plausible
number is still a guess. If you have not seen it in game or in the drop
viewer, do not write it down. A page with four confirmed drops is worth more
than one with forty guessed ones. Mark anything uncertain as uncertain.

**Punctuation.** Use a plain hyphen, not an em dash or en dash. Type three
dots for an ellipsis rather than the single character. Use straight quotes,
not curly ones. Word, Google Docs and Discord all substitute these
automatically, so paste through a plain text editor first.

**Avoid these.** They read as filler, and pages that read that way get
trusted less:

- "It is not just X, it is Y" and its variants
- delve, seamless, robust, leverage, landscape, realm, elevate, unlock,
  harness, testament, crucial, vital
- opening with "In the world of ..." or "When it comes to ..."
- every paragraph arriving in threes
- bold scattered mid sentence for emphasis
- a closing paragraph that repeats what you just said
- emoji as section headers

**Formatting.**

- Tables for anything with more than three data points
- Relative paths when linking to another wiki page
- Check your markdown renders before opening the pull request
